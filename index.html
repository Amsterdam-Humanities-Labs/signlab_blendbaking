Gloss timings API

Get the gloss SRT timings of every baked sentence as JSON — one record per sentence, with each sign's gloss, its Signbank senses, its start and end time, links to all three annotation tiers, and the matching FBX animation.

Added 2026-09-03. Every sentence now returns links to all three annotation tiers — srtUrl (glosses, unchanged), nederlandsSrt (the Dutch sentence) and gvgSrt (sign-by-sign Dutch) — and every gloss cue carries a senses array holding the meanings Signbank NGT records for that sign. Nothing was removed or renamed.

Connecting

Endpointapi.php
MethodGET
Responseapplication/json; charset=utf-8
AuthenticationNone. The data is public and read-only.
CORS Access-Control-Allow-Origin: * — browser clients on any origin can call this directly, no proxy needed. The FBX files it links to are served with the same header.
Errors Always HTTP 200 with {"success": false, "error": "..."} in the body. Check success, not the status code. Error messages are in Dutch.

Getting SRT timings per sentence

One call returns everything you need to drive a player: 

GET api.php?action=timings&base=M20260506_0579

Parameters, all optional — with none of them you get the whole corpus, paged:

ParameterTypeMeaning
base / bases string One video base filename, or several comma-separated (bases=A,B,C). Use one comma-joined value rather than a repeated parameter — PHP's max_input_vars silently drops repeated params past 1000.
sentenceId int Only the video(s) for this sentence. One sentence can have several baked takes.
gloss string Only sentences containing this base gloss — the folded form without the variant letter, so gloss=HUILEN matches HUILEN-A and HUILEN-B. Case-sensitive.
search string Free-text match on base filename or sentence text.
mcpStatusTijdAnnotatie string Klaar, Check nodig or Niet Klaar.
page int 1-based. Default 1.
limit int Sentences per page. Default 25, silently capped at 200 — each sentence in a page costs one SRT read on the server.

The three annotation tiers

ELAN exports one SRT per annotation tier. All three are returned for every sentence, and all three share one timeline, so they can be laid over each other directly:

FieldTierWhat's in it
srtUrl Signbank ID glossen One cue per sign, the gloss as annotated. This is the tier glosses is parsed from — the field keeps its original name so existing clients are unaffected.
nederlandsSrt Nederlands The Dutch sentence as a single cue spanning the whole utterance. Same text as the zin field, but timed.
gvgSrt Gebaar-voor-gebaar Sign-by-sign Dutch — one cue per sign, roughly parallel to the gloss cues, giving the word each sign stands for in this sentence rather than the sign's dictionary meanings.

These are links, not parsed cues — fetch and parse them if you need their timings. Both are present for every baked sentence in the corpus today, but a field is null rather than a broken link when a tier is missing, so check before using it. A fourth tier (_Handvorm.srt) exists for only a handful of bases and is not exposed.

Glosses and senses

Each gloss carries a senses array: the meanings Signbank records for that sign, looked up in the glosses_transformed.json export shipped with this tool. A sense is a comma-separated list of near-synonyms exactly as Signbank writes it, and a sign can have several: 

"gloss": "BINNEN-A",
"senses": [
  "entree, toegang, toegankelijk",
  "binnen, erin, in, van binnen"
]
  • The lookup is on the exact annotated gloss, not the folded baseGloss — Signbank has HUILEN-A but no HUILEN. A handful of cues differ from Signbank only in case (PT-1HAND for PT-1hand); those fall back to a case-insensitive match, which is unambiguous because no two Signbank glosses differ only by case.
  • senses is [], never null, when nothing is found. That covers two different situations: the gloss is in Signbank but carries no senses (nvt is the common one), or it isn't in Signbank at all (PO+PT, -, and a long tail of one-off annotations).
  • Coverage as of 2026-09-03: 98.4% of distinct cues resolve. Excluding nvt, which is a real cue meaning "no gloss assigned here", 98.4% of gloss occurrences carry senses.
  • The export is a point-in-time copy of Signbank, refreshed by hand. It can lag newly added signs.

Things worth knowing

  • Timings and the FBX belong to the same take. fbxUrl is derived from the take that was actually baked, so the cue times line up with that animation's timeline. When fbxIsLatestTake is false, a newer take of the same sentence exists but has not been baked — the FBX you get is the newest one that has been.
  • Times are relative to the recording, not to the first sign. Sentences typically start signing around the 1 second mark, which is why firstStartMs is rarely 0.
  • gloss vs baseGloss. HUILEN-A and HUILEN-B are two annotated variants of one sign; both fold to HUILEN. Group on baseGloss, display gloss. The folding is case-sensitive, and the corpus does contain both PT-1hand and PT-1HAND — they do not fold together.
  • nvt is a real cue. It marks a stretch of signing with no gloss assigned. It is returned like any other; filter it out yourself if you don't want it.
  • A sentence with an unreadable SRT is still returned, with glosses: [] and a message in srtError — so total always matches what you can page through, and a broken file is visible rather than silently missing.
  • Counts are videos, not sentences. total counts baked videos; one sentence with two baked takes is two records with the same sentenceId.
  • Results are cached for 10 minutes server-side. Newly baked takes show up on the next cache expiry.

Examples

curl — one sentence:

curl -s 'api.php?action=timings&base=M20260506_0579'

JavaScript — highlight the current sign while an animation plays:

const res  = await fetch('api.php?action=timings&base=M20260506_0579');
const data = await res.json();
if (!data.success) throw new Error(data.error);

const sentence = data.sentences[0];
console.log(sentence.zin, sentence.fbxUrl);

// Which sign is showing at a given playback position?
function glossAt(ms) {
  return sentence.glosses.find(g => g.startMs <= ms && ms < g.endMs) || null;
}

// ...and what does it mean?
const g = glossAt(3000);
if (g) {
  console.log(g.gloss, g.senses.length ? g.senses[0] : '(no senses in Signbank)');
}

Python — page through every sentence containing a gloss:

import requests

API = 'api.php'

def sentences(**params):
    page = 1
    while True:
        r = requests.get(API, params={'action': 'timings', 'page': page,
                                      'limit': 200, **params})
        d = r.json()
        if not d['success']:
            raise RuntimeError(d['error'])
        yield from d['sentences']
        if page * d['limit'] >= d['total']:
            return
        page += 1

for s in sentences(gloss='HUILEN'):
    for g in s['glosses']:
        if g['baseGloss'] == 'HUILEN':
            print(s['base'], g['gloss'], g['start'], '->', g['end'],
                  '|', '; '.join(g['senses']))

Other actions

These back the two tabs of this page. They are stable but shaped for the UI rather than for integration — prefer timings.

ActionReturns
action=list Baked videos with a gloss SRT, proxied from the upstream corpus API, each row given an extra fbxUrl. Params: search, mcpStatusTijdAnnotatie, page, limit (default 500).
action=glosses The whole base-gloss vocabulary: occurrence counts, video counts, spelling variants, every occurrence, and the category map. refresh=1 forces a rebuild.
action=categories The hand-curated category map on its own.
action=zip Streams a ZIP of gloss SRTs. POST a single comma-joined bases field. Responds with JSON on error, so check Content-Type before treating the body as a file.
